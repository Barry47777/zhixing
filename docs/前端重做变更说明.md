# 知行前端重做 · 变更说明

日期：2026-11-27  
范围：仅 `src/` 前端、静态资源与文档；**后端 API、数据结构、导出/迁移功能未改动**。

## 1. 目标与风格映射

| 模块 | 还原对象 | 结果 |
| --- | --- | --- |
| 今日 / 日历 / 统计 / 项目 / 设置 | `studio-log-pro` | 浅色 Studio Log 原皮肤：白卡片、靛蓝强调、月历网格、拖拽改期、项目拖拽排序、数值拖动 |
| 灵感 / 复盘 | `inspiration`（复盘 · Edge） | 深色玻璃紫原皮肤：极光背景、瀑布流便签墙、五秒速记、全文阅读页、复盘时间流与归因 |

两套皮肤用 `html[data-skin]` 隔离：工作区跟随全局主题设置，思维区使用独立的明暗偏好（默认暗色），互不污染。

## 2. 设计基础层

- 重写 `src/styles/tokens.css`：Studio 与 Edge 两套令牌按 `data-skin` 分组。
- 移植 `styles/studio-tokens.css`、`styles/studio.css`；`styles/edge/` 下由原版 CSS 经 `scripts/scope-edge-css.mjs` 自动加 `.edge-app` 作用域生成 5 份 scoped 样式。
- `index.html` 默认浅色；新增 `public/manifest.webmanifest`、`public/favicon.svg`，消除控制台 404。

## 3. 数据适配层（全部读写仍走现有 `/api`）

- `types.studio.ts`：Studio 形状的类型定义。
- `stores/data.ts`：条目 / 项目 / 模板 / 日总结 / 附件 / 回收站的 Studio 形状适配。
- `stores/session.ts`、`stores/settings.ts`：会话与设置字段映射（如 `dailyGoal ↔ dailyGoalHours`、`defaultHours ↔ defaultMinutes`）。
- `stores/edge.ts`：思维区独立主题状态，存 `localStorage`。
- `utils/edge.ts`、`utils/color.ts` 等：文本处理、强调色映射。

## 4. 组件与页面

### 工作区
- 侧栏回归原版结构：**日历 / 统计 / 项目**，下方单独分组「思维区」放灵感 / 复盘；底部为主题切换与「设置与数据」（快捷键 1–6）。
- `CalendarView / DayCell / DayDrawer / EntryForm / ProjectsView / ProjectModal / StatsView / DragNumber / DateField / AttachmentGrid / ToastHost / ConfirmHost` 的模板与样式与 Studio Log 原版一致，仅脚本改为调用知行数据层。
- `TodayView` 重做；`SettingsView` 改为对接本机服务（存储位置、快照、备份、导入、清理、回收站、演示数据）。
- 顶栏搜索、月份切换、记录抽屉、复制昨天、当日总结自动保存、项目滑杆与数值拖动均可用。

### 思维区
- `EdgeTop / NoteCard / NoteReader / LightBox / ReviewDrawer / NotesView / ReviewView` 按原版类名与结构重建，复用原版 CSS。
- 补回原版顶栏的 **底线（不做清单）**、**切换主题**、**导入 / 导出** 三颗按钮；底线抽屉列出带「底线」标签的笔记，可一键带着该标签写新条目；导入导出指向工作区设置页。
- 新增清晰的 **「← 工作台」** 返回入口；跨区引用用 `?note=<id>` 深链，浏览器后退可回到来源区。
- 全文阅读页顶部紫粉渐变进度条按滚动比例推进（`scaleX`），滚动超过 6px 进入 `is-scrolled` 态。
- 复盘页「记录 / 归因」二级导航、未结 / 已结 / 层级筛选、结果冻结与成长归因等交互按原版恢复。

## 5. 本轮补充审计发现并修复的问题

| 问题 | 修复 |
| --- | --- |
| 全局主题初始化把思维区覆盖成浅色 | `App.vue` 统一 `syncTheme()`，监听皮肤 / 全局主题 / Edge 主题三个来源 |
| `Icon` 只认 `stroke`，原版组件传 `stroke-width`，且默认线宽 1.6 与原版 1.7 不符 | 两种属性都支持，默认恢复 1.7 |
| 灵感筛选缺少「灵感 / 心得」类型按钮 | 补回类型筛选并接入「清筛选」 |
| 复盘「未结 / 已结 / 想法 / 判断 / 交易」筛选条件写反，切归因视图不清筛选 | 改为记录视图显示，切归因时重置 |
| 复盘详情抽屉缺 `.open` 类，实际一直停在屏幕外 | 挂载后下一帧加 `.open`，滑入动画恢复 |
| Edge 顶栏少了底线 / 导入导出按钮，主题开关改的是全局设置 | 补齐按钮；主题改为思维区独立状态 |
| 移动端顶栏按钮被裁切 | 窄屏隐藏导入导出（设置页仍可进入），无横向溢出 |
| 部分原版 CSS 依赖的 `#search`、`#editor`、`#modalEditor`、`#lbImg` 等 ID 未落到组件上 | 全部补齐，相关样式生效 |
| 遗留的旧版组件仍在源码里 | 删除 `EntryDrawer / GlobalSearch / SideNav / NoteQuickCompose / PageStub / InsightsView` |

## 9. 首页模块化定制（回到今天）

- 新增 `src/stores/home.ts`：首页布局声明、默认值、归一化、本地持久化、导入 / 导出。只保存「怎么摆」，数据仍走现有 store 与 `/api`。
- 新增 `src/components/home/HomeEditor.vue`：定制抽屉，支持布局方式（自适应网格 / 单列 / 紧凑）、模块拖动排序、改名、宽度、显示隐藏、复制删除、恢复默认、JSON 导入导出。
- 重写 `src/views/TodayView.vue`：首页改为 12 栏模块网格；模块包括今日概览、本周节奏、快速记录、今日记录、当日总结、翻一张旧牌、项目轨道、最近灵感、常用标签、数字速览、快捷入口、自定义便签。
- 每个模块可独立设置内容参数：今日记录支持状态 / 项目 / 条数筛选；最近灵感支持分区 / 条数；项目与标签支持条数；概览可隐藏本周节奏；快捷入口可勾选动作；便签可写自定义文案。
- `SideBar.vue`：「回到今天」现在始终进入可定制首页，并在本周区块新增「定制」快捷入口。
- 布局保存在浏览器 `localStorage`（`zhixing.home.layout.v1`），不影响 `data/workspace.json`，也不改变后端 API、导出 / 迁移格式。
- 验证：`vue-tsc --noEmit` 通过，`npm run build` 通过，`npm test` 42/42 通过；无头浏览器冒烟确认改名、添加模块、切换单列、保存与回读均正常。
