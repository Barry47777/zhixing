# 知行 · 设计系统

> 概念：**轨道观测台（Orbital Observatory）**。深空底色、极细的仪器刻度、玻璃与微光；数据像光点一样被观测，而不是堆在表格里。克制的科幻，不赛博。

## 1. 设计原则

1. **一屏一个主视觉**：今日是「轨道目标环」，日历是「月格」，灵感是「速记 + 墙」，复盘是「时间流」，洞察是「热力图」。其余元素服务于它。
2. **等宽左右边界**：每个视图内容都落在同一栅格（padding 32，最大 1440），左标题、右筛选，从不东倒西歪。
3. **玻璃只用于层**：浮层/导航/卡片三层玻璃，不高频叠加；背景永远有极淡的极光与颗粒，避免死黑。
4. **数字是主角**：大数字用 Space Grotesk + 等宽数字（tnum），标签用 JetBrains Mono 小号大写；中文正文用系统黑体，保证阅读。
5. **动效有因果**：出现、悬停、切换、数值变化才动；不滚动淡入、不视差、不劫持滚动；一切动效在 `reduce-motion` 下变为瞬时。
6. **克制的颜色**：主色只有一个强调色（可在设置里换），其余用中性灰阶；盈亏/胜负用低饱和的红绿，字号不大于正文。禁用紫罗兰/薰衣草色。
7. **触控与键盘都第一等**：控件≥44px 触控区，焦点环常驻，快捷键覆盖主流程。

## 3. 字体

- 拉丁/数字展示：**Space Grotesk**（woff2，400/500/600/700，本地打包，`font-display:swap`）。
- 数据/序号/时间/标签：**JetBrains Mono**（400/500/600，本地打包）。
- 中文：系统栈 `"PingFang SC","HarmonyOS Sans SC","Microsoft YaHei UI","Noto Sans SC",sans-serif`。
- 组合栈：`--font-sans: "Space Grotesk","PingFang SC",…,sans-serif`；`--font-mono:"JetBrains Mono",ui-monospace,monospace`。
- 字号：`--fs-display:44px`、`--fs-h1:26px`、`--fs-h2:20px`、`--fs-h3:16.5px`、`--fs-body:14.5px`、`--fs-sm:12.5px`、`--fs-micro:11px`。行高：display 1.1、标题 1.3、正文 1.65。
- 数字：`font-variant-numeric: tabular-nums`；大数字字重 500–600，字距 `-0.02em`。
- 小标签：mono 11px，`letter-spacing:.09em`，`text-transform:uppercase`（中文不转换）。

## 4. 空间、圆角、层级

- 间距基数 4：`4/8/12/16/20/24/32/40/48/64`。
- 容器：桌面视图 padding 28–32；卡片内 18–22；卡片间距 14–18。
- 圆角：`--r-xs:8px --r-sm:10px --r-md:14px --r-lg:18px --r-xl:24px --r-pill:999px`。
- 发丝线 1px；仅浮层用 `backdrop-filter: blur(22px) saturate(150%)`；无 backdrop-filter 时回退不透明面板。
- 层级：背景 0 / 内容 1 / sticky 栏 10 / 抽屉 40 / 模态 50 / toast 60。

## 5. 组件规范

- **按钮**：高度 44（sm 36 / lg 48）；圆角 12；primary=实心强调色+ink 文字；secondary=玻璃+发丝线；ghost=透明悬停显形；danger=红；按下 `scale(.985)`；禁用 40% 透明度。
- **输入**：高 44，内嵌玻璃底，聚焦强调色边框+2px 外环；placeholder `--text-3`；错误红边+一行说明。
- **卡片**：glass 面 + 1px line + 18px 圆角 + 内高光；hover 抬 2px、线变亮；可点击卡片给 `cursor:pointer`。
- **分段控件**：胶囊轨道 + 滑块（transform 动画 180ms），选中文字 `--text`。
- **标签 chip**：12px，1px 线，hover 强调色线；选中=强调色 soft 底。
- **图标**：内联 SVG，24 网格，1.6 描边，圆角端点；不引图标库。
- **抽屉**：右侧，宽 480（记录）/ 560（笔记详情），玻璃，224ms 滑入；scrim `rgba(0,0,0,.45)`+blur(2px)；Esc/点外关闭；移动端从底部全屏。
- **模态**：居中，最大 720/880，24px 圆角；头部标题+关闭；底部操作右对齐；焦点陷阱。
- **Toast**：底部居中，玻璃胶囊，2.8s；带一个可选操作（撤销）。
- **空态**：一个细线图形（SVG 轨道/星点）+ 一句事实 + 一个动作，不用大插画。
- **加载**：骨架微光（1.4s 循环）；不用全屏 spinner（首屏除外）。

## 6. 页面构图

### 今日
- 顶部 hero：左侧「2026年11月26日 · 周三 / 傍晚好」+ 一句当天提示（真实数据，如「今天已投入 3.5h，还有 2 个项目在推进」）；右侧 240px **轨道目标环**（刻度 24 段、进度弧、中心 `3.5 / 6h`、环上小点表示完成条目）。
- 第二行 12 栏栅格：左 7 栏「今日时间线」（纵向发光线 + 记录节点，行内项目色点/时长/状态，底部 + 添加记录）；右 5 栏「速记」（textarea + 标签 + 记下按钮）与其下「今天想到的」列表（最多 4 条）。
- 第三行：3 张卡「待复盘」（盲卡/到期）、「项目推进」（3 个项目进度条）、「连续记录」（迷你热力+天数）。
- 所有模块真实数据；空态给下一步动作。

### 日历
- 顶栏：`2026 年 11 月` + 前后/今天 + 本月投入/目标 + 图例。
- 7×6 月格；格高≥108；日号（今天=强调色实心圆）、当日总工时（超目标强调色）；每条记录一个小条（项目色左边 2px + 标题 + 时长），最多 3 条再 `+N`；底部标记：有总结/有附件/有受阻；当天有笔记时右上角 2px 星点（最多 3 个）；跨月格降透明度；拖拽换日。
- 点格子开「日抽屉」：头部日期/统计/目标条；记录列表；当天笔记；总结；生成日报。

### 项目
- 顶部标题 + 新建；筛选（进行中/暂停/归档/全部）。
- 卡片网格：左上项目色发光线，名称+状态，进度环（或细进度条）+百分比，本周目标进度，到期倒计时，记录数/工时；拖拽排序；hover 显示操作。
- 点击开项目详情（路由页或宽抽屉）：项目头图（色相极光）、KPI（总工时/本周/记录数/关联笔记）、近 8 周柱、记录列表、相关思考、编辑/归档/合并/删除。

### 灵感
- 速记卡：大 textarea（自动增高，最多 300px）、图片条、标签、加图/记下；Enter 保存、Shift+Enter 换行。
- 工具栏：布局（瀑布/网格/列表）、时间（全部/今天/近 7/近 30 + 30 天柱）、排序、标签筛选、搜索框；一屏内不重复大标题。
- 墙：瀑布用 CSS columns；卡片含 #序号、类型、正文（最多 7 行/180 字折叠）、图、标签、时间、留言数；hover 微抬。
- 阅读页：居中 780px 玻璃层，顶部 #序号·类型、标题、时间·字数·留言；正文 16px/1.9；图片单列或并排；标签；引用/被引用 chip；留言区；底部复制/编辑/完成；滚动进度线。

### 复盘
- 顶部双标签：`记录` / `归因` / `校准`（记录与归因是两种看同一批数据的方式；校准是深度工具）。
- 记录：富文本框（字号/粗斜下划线删除线/6 色/对齐/列表）、图片、标签、状态标签、置顶；墙按时间/标签/状态筛选；卡片含层级、冻结/底线角标、交易要素 bits、结果、事后、留言。
- 归因：完整时间流；已结/未结分色；详情抽屉：正文、事后、四组快捷标签（结果/把握/成长/错误归因）、当时写下的细节、引用、变更、编辑；冻结记录改正文必须先写修订理由。
- 校准：盲卡（抽一张旧判断先重判再揭晓）、周回顾（摊开→限票 3→写一条行动）、五个待办（补全/归因/成长/结结果/复核）、四组尺子（校准/错误/成长/执行）。用仪表盘式卡片。

### 洞察
- 顶部范围切换（本月/近三月/今年/自定义）。
- KPI 条：投入小时/活跃天数/日均/完成率（工作）+ 记录数/已结/胜率/成长（思考）。
- 52 周热力图（全宽，格子 hover 显示日期+工时）；近 8 周柱 + 状态环 + 项目占比；标签云；错误归因分布；校准散点（把握 vs 结果）；执行度条形。
- 全部用 SVG 手绘，强调色单一，网格极淡。

### 设置
- 左侧子导航：外观 / 偏好 / 数据与安全 / 关于。
- 外观：主题三态、7 强调色色板、密度、字号滑杆、减少动效、周起始、显示周数。
- 偏好：每日目标、默认项目/时长、开始页。
- 数据与安全：数据地址与状态、存储占用、快照列表（创建/恢复/下载/删除）、导出（全量/笔记/工作）、导入（拖放/选择/预览）、回收站、旧数据迁移（inspiration 服务端扫描 + studio-log 文件导入）、危险区（清空数据双重确认）。
- 关于：版本、快捷键表、设计说明、致谢两个前身。

## 7. 动效

| 场景 | 规范 |
|---|---|
| 视图切换 | opacity 0→1 + translateY(6px)，180ms，cubic-bezier(.2,.7,.2,1) |
| 卡片入场（仅首屏） | 30ms 级联，最多 12 张，260ms |
| 卡片 hover | translateY(-2px)，阴影加深，160ms |
| 按钮按下 | scale(.985)，90ms |
| 目标环/进度弧 | stroke-dashoffset 900ms ease-out |
| 柱状/热力 | scaleY 0→1，500ms，级联 12ms |
| 数字变化 | rAF 补间 500ms，显示时四舍五入 |
| 抽屉/模态 | 224ms slide+fade；关闭 160ms |
| 极光 | 40s 缓慢位移（仅桌面、非减少动效） |
| 减少动效 | 全部改为 0ms/无 transform；`prefers-reduced-motion` 或设置项任一命中 |

## 8. 响应式

- ≥1280：完整三栏（rail 232 + 内容 + 抽屉）。
- 1024–1279：rail 收成 68px 图标，hover 展开浮层。
- 768–1023：内容 padding 20；日历格精简（每天 2 条）；详情用整页抽屉。
- <768：底部 5 项导航（今日/日历/灵感/复盘/更多），顶部搜索收起为图标；抽屉全屏；墙单列；热力图 26 周；输入字号 16px 防 iOS 缩放。

## 9. 文案语气

- 短句、具体、有人味，不喊口号；不用「赋能/闭环/生态」等空词。
- 空态：陈述事实 + 下一步（「今天还没有记录。写下第一件事，日历会记住它。」）。
- 错误：说清发生了什么、数据是否安全、下一步怎么做（「没能写进磁盘，这次改动已撤回。检查磁盘空间，或到数据中心导出备份。」）。
- 成功：极短（「记下了」「已保存」「已恢复」），不弹窗庆祝。
- 数字带单位且一致：`3.5h`、`42 分钟`、`12 条`、`#102`。

## 10. 禁止项（防走偏）

- 不用紫罗兰/薰衣草主色；不用彩虹渐变按钮；不用玻璃叠玻璃三层以上。
- 不用无意义大插画、emoji 装饰、闪烁光标、自动轮播。
- 不把两套旧 UI 直接拼在一起；所有页面共用同一 Shell、同一卡片、同一筛选条。
- 不牺牲可读性换科技感：正文对比≥4.5:1，图表有文字标签，颜色不是唯一信息通道。
- 不在记录时追问结构化字段：工作记录只需一句话，思考只需正文；其余都可事后补。
